# Changelog

[日本語](CHANGELOG.md)

Fix numbers refer to the list in the [README](README.en.md#features) of that version.

## [v2026.10.19](https://github.com/nagataaaas/wots4-unofficial-patch/releases/tag/v2026.10.19)

- Added fix 3: switching to another window could crash the game.
- Added fix 7: more than 65 sound effects never played.
- Added fix 8: after fishing, the voices of shopkeepers and others stopped playing.
- Reordered the README's list of fixes by impact. The fix numbers change from this version.

## [v2026.10.18](https://github.com/nagataaaas/wots4-unofficial-patch/releases/tag/v2026.10.18)

- Added fix 11: the game froze for minutes when starting to play or when opening Options for the first time.
- Added fix 12: a body with nothing left to obtain could be searched again and again without giving anything.

## [v2026.10.14.6](https://github.com/nagataaaas/wots4-unofficial-patch/releases/tag/v2026.10.14.6)

- Tidied up the description of fix 9 in the README. No changes to how the Mod works.

## [v2026.10.14.5](https://github.com/nagataaaas/wots4-unofficial-patch/releases/tag/v2026.10.14.5)

- Added fix 10: the game could crash when you chose New Game after opening Options on the title screen, or loaded a save that had finished a playthrough.

## [v2026.10.14.4](https://github.com/nagataaaas/wots4-unofficial-patch/releases/tag/v2026.10.14.4)
