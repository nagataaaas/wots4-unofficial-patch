# bug_fix

[English](README.en.md)

『侍道4』のクラッシュやバグを直す Mod です。

Release にはまだ入れていません。

## 直すもの

修正ごとの詳しい説明（どんな問題か・なぜ起きるか・考えた対策・採った対策・備考）は [`docs/fixes/`](docs/fixes/) にあります（英語）。

1. 牢屋の写真家から再開すると、真ルートの結末（鬼怒川を倒した直後）でクラッシュする問題（ゲームで確認済み。[詳細](docs/fixes/jail_ending_crash.md)）
   - クラッシュせずに結末まで進みます。
2. 「士魂は屈せず」でまだらに助けられたとき、取り上げられた武器・アイテム・服が返ってこない問題（ゲームで確認済み。[詳細](docs/fixes/madara_rescue_property.md)）
   - まだらに助けられる流れは通常のプレイにはなく、セーブエディタなどでフラグを書き換えたときにしか起きません。
   - 助けられたあとに、持ち物が返ってきます。
   - すでにこの状態で保存したセーブの武器は戻せません。
3. 光（bloom）や蹴ったときのエフェクトなどに、白や黒の四角が付く問題（ゲームで確認済み。[詳細](docs/fixes/effect_box.md)）
   - エフェクトの周りに四角が出なくなります。被写界深度（DoF）を有効にしたまま使えます。
4. 全画面で、ウィンドウに戻るたびに画面が白くなって一瞬止まり、画面の外まで広がって見える問題（ゲームで確認済み。[詳細](docs/fixes/focus_white_screen.md)）
   - Windows の拡大率が 100% でないときに起きていました。
   - ウィンドウに戻ったとき、白くならずにすぐ戻ります。
5. 夜這いのあと、セーブせずに「タイトルに戻る」から夜這いの約束があるセーブをロードすると、古い褒美（愛の証・慰めの品）がまた地面に落ち、約束が消える問題（要ゲーム内確認。[詳細](docs/fixes/yobai_result_after_title.md)）
   - ロードしたセーブの約束はそのまま残り、古い褒美は出ません。
   - 死んで「リトライ」したときは、ゲームのとおりに夜這いの褒美が出ます。

## 設定（config.ini）

`mods/bug_fix/config.ini` に、修正ごとの節（`[<修正名>]`）があります。`enabled=1` でその修正を入れ、`0` で入れません（ゲームはそのままです）。ファイルや項目がないときは、すべての修正を入れます。

| 節 | 修正 |
| --- | --- |
| `[follow_detach]` | 1. 牢屋の写真家から再開したときの結末のクラッシュ |
| `[property_return]` | 2. まだらに助けられたときに持ち物が返らない |
| `[translucent_depth]` | 3. エフェクトの白や黒の四角 |
| `[physical_screen_check]` | 4. ウィンドウに戻るたびの白画面と停止（解像度の判定） |
| `[skip_full_screen_reapply]` | 4. ウィンドウに戻るたびの白画面と停止（全画面のかけ直しの省略） |
| `[no_white_background]` | 4. ウィンドウに戻るたびの白画面と停止（背景を白で塗らない） |
| `[yobai_result_reset]` | 5. タイトルに戻ったあとに夜這いの褒美がまた出る |

`1` と `0` 以外の値は `1` として扱います。設定は起動したときに読みます。

## 修正を足す・変えるとき

1. [`docs/fixes/TEMPLATE.md`](docs/fixes/TEMPLATE.md) を写して `docs/fixes/<修正名>.md` を作り、すべての節を埋めます。
2. 修正のコードを作るとき・変えるときは、同じ変更の中でその文書も更新します（状態・原因・採った対策・テストの結果など）。
3. 上の「直すもの」の一覧も合わせて直します。
4. `config.ini` に修正の節を足し、上の「設定」の表も直します。

## ビルド

ふつうは [wots4-mods](https://github.com/nagataaaas/wots4-mods) の中でビルドします。この Mod だけをビルドするときは、`-DWOTS4_SDK_DIR=<wots4-mods のパス>` を付けて CMake を実行します。
