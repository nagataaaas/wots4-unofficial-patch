# crash_fix

『侍道4』のクラッシュを減らす Mod です。

**まだ修正は入っていません。** 入口だけがあり、Release には入れていません。

## 予定

1. 牢屋の写真家から再開すると、真ルートの結末でクラッシュする問題
2. ほかのクラッシュ（ウィンドウに戻ったときに画面が白くなって止まる、など）

## ビルド

ふつうは [wots4-mods](https://github.com/nagataaaas/wots4-mods) の中でビルドします。この Mod だけをビルドするときは、`-DWOTS4_SDK_DIR=<wots4-mods のパス>` を付けて CMake を実行します。
