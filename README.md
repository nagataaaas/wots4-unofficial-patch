# bug_fix

[English](README.en.md)

『侍道4』のクラッシュやバグを直す Mod です。

Release にはまだ入れていません。

## 直すもの

修正ごとの詳しい説明（どんな問題か・なぜ起きるか・考えた対策・採った対策・備考）は [`docs/fixes/`](docs/fixes/) にあります（英語）。

1. 牢屋の写真家から再開すると、真ルートの結末（鬼怒川を倒した直後）でクラッシュする問題（ゲームで確認済み。[詳細](docs/fixes/jail_ending_crash.md)）
   - 人物の骨に付いたエフェクト（オーラなど）が、人物のモデルが解放されたあとも骨を指したまま残り、解放済みの骨を読んで落ちていました。人物のエフェクトを外すとき（`0x48d520`）に、そのモデルの骨に付いたエフェクトもすべて外します。外れたエフェクトは、その場に残ります。
   - 外したときは `mod_loader.log` に `detached N effect(s)` と書きます。
2. 「士魂は屈せず」でまだらに助けられたとき（セーブの `0x3760` が 1）、取り上げられた武器・アイテム・服が返ってこない問題（ゲームで確認済み。[詳細](docs/fixes/madara_rescue_property.md)）
   - このフラグを 1 にする場面は通常のプレイにはなく、セーブエディタなどでフラグを書き換えたときにしか起きません。厳密にはバグの修正というより、作りかけのまま残っている分岐を、通常の流れとそろえるものです。
   - 返す処理（`PlayerGiveProperty`）は三姉妹を倒したあとの場面にしかなく、まだらに助けられる流れでは呼ばれていませんでした。武器の預け先は保存されないので、そのまま保存して読み直すと武器は失われます。スクリプトがまだらに助けられたあとの場面（`BR_14_00_S210`）へ移るとき（`0x55e140`）に、持ち物が取り上げられたままなら、ゲーム自身の返す処理を呼びます。
   - 返したときは `mod_loader.log` に `returned the player's weapons, items and outfit after Madara's rescue` と書きます。
   - すでにこの状態で保存したセーブの武器は戻せません。
3. 光（bloom）や蹴ったときのエフェクトなどに、白や黒の四角が付く問題（ゲームで確認済み。[詳細](docs/fixes/effect_box.md)）
   - シーンは色と、被写界深度（DoF）が読む深度のテクスチャの2枚に同時に描かれます。エフェクトの四角い板は、透明な部分も含めて全面で深度を書き換えていたので、板の形に DoF のぼかしやコントラストが変わっていました。合成（アルファブレンド）で描く間は、深度のテクスチャに書かないようにします（`IDirect3DDevice9::SetRenderState` をフック）。
   - 入ったときは `mod_loader.log` に `translucent depth mask installed` と書きます。

## 予定

1. ほかのクラッシュ（ウィンドウに戻ったときに画面が白くなって止まる、など）

## 修正を足す・変えるとき

1. [`docs/fixes/TEMPLATE.md`](docs/fixes/TEMPLATE.md) を写して `docs/fixes/<修正名>.md` を作り、すべての節を埋めます。
2. 修正のコードを作るとき・変えるときは、同じ変更の中でその文書も更新します（状態・原因・採った対策・テストの結果など）。
3. 上の「直すもの」の一覧も合わせて直します。

## ビルド

ふつうは [wots4-mods](https://github.com/nagataaaas/wots4-mods) の中でビルドします。この Mod だけをビルドするときは、`-DWOTS4_SDK_DIR=<wots4-mods のパス>` を付けて CMake を実行します。
