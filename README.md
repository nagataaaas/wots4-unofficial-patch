# bug_fix

[English](README.en.md)

『侍道4』のクラッシュやバグを直す Mod です。

Release にはまだ入れていません。

## 直すもの

修正ごとの詳しい説明（どんな問題か・なぜ起きるか・考えた対策・採った対策・備考）は [`docs/fixes/`](docs/fixes/) にあります（英語）。

1. 牢屋の写真家から再開すると、真ルートの結末（鬼怒川を倒した直後）でクラッシュする問題（ゲームで確認済み。[詳細](docs/fixes/jail_ending_crash.md)）
   - 人物の骨に付いたエフェクト（オーラなど）が、人物のモデルが解放されたあとも骨を指したまま残り、解放済みの骨を読んで落ちていました。人物のエフェクトを外すとき（`0x48d520`）に、そのモデルの骨に付いたエフェクトもすべて外します。外れたエフェクトは、その場に残ります。
   - 外したときは `mod_loader.log` に `detached N effect(s)` と書きます。

## 予定

1. ほかのクラッシュ（ウィンドウに戻ったときに画面が白くなって止まる、など）
2. 表示などのバグ（粒子の効果の後ろに黒い四角が出る、など）

## 修正を足す・変えるとき

1. [`docs/fixes/TEMPLATE.md`](docs/fixes/TEMPLATE.md) を写して `docs/fixes/<修正名>.md` を作り、すべての節を埋めます。
2. 修正のコードを作るとき・変えるときは、同じ変更の中でその文書も更新します（状態・原因・採った対策・テストの結果など）。
3. 上の「直すもの」の一覧も合わせて直します。

## ビルド

ふつうは [wots4-mods](https://github.com/nagataaaas/wots4-mods) の中でビルドします。この Mod だけをビルドするときは、`-DWOTS4_SDK_DIR=<wots4-mods のパス>` を付けて CMake を実行します。
